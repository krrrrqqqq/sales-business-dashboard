# Данные для демонстрации

`synthetic_sales.csv` — **искусственно сгенерированный учебный набор данных**. Все имена источников, лиды, даты и суммы вымышлены; это не реальные сведения о клиентах или компании.

CSV содержит одну строку на лид. `stage` означает самый дальний этап воронки, которого достиг лид. Для закрытых проигранных сделок сохраняется последний достигнутый этап. `deal_amount` — условная сумма сделки; в выручку включаются только строки со статусом `Won`.
